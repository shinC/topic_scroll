# 구현 계획서 - 구글 시트 출처별 저장 순서 재정렬 (포모스/블라인드 최상위, 정부정책 최하단)

## 1. 개요
- **작업명**: 구글 스프레드시트 기사 출력 위치 재정렬 (포모스/블라인드 최상위, 일반 뉴스 중간, 정부 정책 최하단)
- **일자**: 2026-10-06
- **목적**:
  1. 포모스 및 블라인드 커뮤니티 수집 데이터를 스프레드시트의 최상단에 먼저 배치.
  2. 일반 언론사 RSS 뉴스를 중간에 배치.
  3. 정부24, 고용24, 복지로, 국토교통부, 정책브리핑, 보건복지부 등 정부/공공 포털 정책을 가장 하단에 배치.

---

## 2. 세부 구현 내용

### 1) 우선순위 계산 헬퍼 함수 (`_get_article_priority`) 구현
- `src/pipeline/google_sheets_exporter.py` 내 기사 객체의 `portal_id`, `id`, `site_name`을 검사하는 헬퍼 함수 작성:
  - **Priority 1 (최상단)**: `portal_id` 또는 `site_name`에 `"fomos"`, `"blind"`, `"포모스"`, `"블라인드"` 포함 시 1 반환.
  - **Priority 3 (최하단)**: `gov24`, `work24`, `bokjiro`, `molit`, `korea`, `mohw`, `정부`, `복지로`, `보건복지부`, `정책브리핑` 등 정부/공공 출처 포함 시 3 반환.
  - **Priority 2 (중간)**: 일반 언론사 RSS 뉴스 항목에 2 반환.

### 2) 구글 시트 내보내기 전 정렬 적용
- `export()` 실행 시 `sorted_articles`를 생성:
  - 1차 키: `_get_article_priority(article)` (1 -> 2 -> 3)
  - 2차 키: `published_at` 내림차순 (동일 우선순위 그룹 내에서는 최신 기사 우선)
- 정렬된 기사 목록을 기존 20개 단위 빈 행 분할 저장 로직과 조합하여 구글 스프레드시트('시트1')에 덮어쓰기.
